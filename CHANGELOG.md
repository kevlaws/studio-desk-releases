# Release notes

## 1.0.0 — 5 November 2026

First public release of Studio Desk for Windows x64.

- Current-user installer with Start menu and optional desktop shortcuts.
- Portable ZIP for running without installation; .NET runtime included in both.
- Five dashboard views and remembered independent monitor arrangements.
- Original RØDECaster Pro MIDI tracking, mute sync and diagnostic learn.
- ON AIR lamp, studio clocks, timers, stereo meters and custom channel labels.
- Jingle banks, overlapping playback, loops, fades and local Show-bank import.
- Notes, labelled RSS headlines, weather and sourced show-prep cards.
- Neon red ON AIR Windows icon.

Existing private development profiles are compatible. Current hardware states
still require fresh readings or confirmation after every reconnect.

This release is unsigned. Jingle audio, personal settings and application source
are not included in the public assets. See the setup guide for hardware limits.
